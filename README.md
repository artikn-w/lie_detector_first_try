# Face Motion Lab

Приложение измеряет движения лица с веб-камеры. Оно показывает частоту моргания за последние 15 секунд, приближённую угловую скорость головы и отклонения положения губ и бровей от личной базы. График показывает частоту моргания за последние 10 секунд. Положение головы приближённое, поскольку используется модель лица и оценка параметров камеры.

## Запуск

Python 3.11 или 3.12, камера и графический рабочий стол.

```sh
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Первые три секунды смотрите прямо и расслабьте лицо. Частота моргания появляется после пяти секунд устойчивого трекинга. Кнопка «Калибровать заново» (R) повторяет калибровку в обычном режиме. Кнопка «Закрыть» (Q или Esc) закрывает окно. На Linux может потребоваться системный пакет Tkinter для вашей версии Python. Для другой камеры используйте `--camera 1`.

## Эксперимент

Записывайте только с согласия участников. Используйте псевдонимы. Для каждого человека соберите правдивые и заведомо ложные ответы сопоставимой длины, меняя порядок и сохраняя одинаковые условия. Запускайте отдельную запись для каждого ответа. После появления частоты моргания нажмите «Начать запись» (пробел) непосредственно перед ответом и «Завершить запись» сразу после него. Для каждого файла требуется минимум десять валидных измерений.

```sh
mkdir recordings
python main.py --record recordings/p01-t01.csv --participant p01 --trial t01 --label truth
python main.py --record recordings/p01-t02.csv --participant p01 --trial t02 --label lie
python evaluate.py recordings/*.csv
```

CSV содержит только измерения и метаданные пробы. Видео и звук не сохраняются. Скрипту оценки нужны минимум три участника с обоими типами ответов. Он сводит измерения каждого ответа к среднему и разбросу, обучает логистическую регрессию и проверяет её на полностью отложенном участнике, по очереди для всех людей. Вывод включает сбалансированную точность и долю правдивых ответов, ошибочно классифицированных как ложь. Три участника позволяют проверить работу скрипта. Для выводов о переносимости модели нужны дополнительные участники и независимая выборка. Любой результат относится к условиям конкретного эксперимента.
